# Project Scope

## Objetivo

Definir claramente los límites funcionales y técnicos del Sistema de Gestión de Horarios SENA.

---

# Alcance Funcional

El sistema permitirá gestionar la programación académica institucional mediante los siguientes módulos.

---

# Gestión de Usuarios

Incluye:

- Registro de usuarios.
- Actualización de usuarios.
- Gestión de roles.
- Gestión de permisos.
- Control de acceso.

---

# Gestión de Instructores

Incluye:

- Registro de instructores.
- Actualización de información.
- Consulta de asignaciones.
- Gestión de disponibilidad.

---

# Gestión de Aprendices

Incluye:

- Registro de aprendices.
- Consulta de información.
- Asociación a fichas.

---

# Gestión de Programas

Incluye:

- Registro de programas.
- Consulta de programas.
- Parametrización académica.

---

# Gestión de Ambientes

Incluye:

- Registro de ambientes.
- Administración de capacidad.
- Consulta de disponibilidad.

---

# Gestión de Horarios

Incluye:

- Creación de horarios.
- Modificación de horarios.
- Eliminación de horarios.
- Consulta de programación.

---

# Gestión de Reportes

Incluye:

- Reportes de horarios.
- Reportes de ocupación.
- Reportes de disponibilidad.

---

# Alcance Técnico

El proyecto contempla:

- Arquitectura basada en microservicios.
- API Gateway.
- Base de datos relacional.
- Frontend web.
- Autenticación JWT.
- Auditoría.

---

# Fuera del Alcance

Las siguientes funcionalidades no forman parte de esta versión:

- Nómina institucional.
- Gestión financiera.
- Gestión presupuestal.
- Gestión contractual.
- Gestión documental institucional.
- Integración con sistemas externos no definidos.

---

# Restricciones

- El sistema requiere conexión a internet.
- Los usuarios deben estar autenticados.
- La información dependerá de la disponibilidad de los servicios.

---

# Supuestos

- Los usuarios cuentan con credenciales institucionales.
- Los datos académicos son suministrados por las áreas responsables.
- La infraestructura tecnológica estará disponible para el despliegue.

---

# Criterios de Éxito

El proyecto será considerado exitoso cuando:

- Reduzca conflictos de programación.
- Mejore la trazabilidad.
- Centralice la información académica.
- Cumpla los requisitos funcionales definidos.
