# User Manual

## Objetivo

Proporcionar a los usuarios finales una guía para utilizar correctamente el Sistema de Gestión de Horarios SENA.

---

# Introducción

El Sistema de Gestión de Horarios SENA permite administrar la programación académica institucional, facilitando la consulta y gestión de información relacionada con horarios, instructores, aprendices y ambientes.

---

# Acceso al Sistema

## Requisitos

- Usuario activo.
- Contraseña válida.
- Acceso a internet.
- Navegador compatible.

---

# Inicio de Sesión

### Pasos

1. Ingresar al sistema.
2. Escribir correo institucional.
3. Ingresar contraseña.
4. Presionar "Iniciar Sesión".

### Resultado Esperado

Acceso exitoso al Dashboard.

---

# Dashboard

El Dashboard presenta:

- Accesos rápidos.
- Información relevante.
- Indicadores generales.

---

# Consulta de Horarios

### Pasos

1. Ingresar al módulo Horarios.
2. Seleccionar filtros.
3. Ejecutar búsqueda.

### Resultado

Visualización de horarios asignados.

---

# Consulta de Programas

Permite visualizar:

- Programas de formación.
- Fichas.
- Información académica.

---

# Consulta de Ambientes

Permite consultar:

- Disponibilidad.
- Capacidad.
- Ubicación.

---

# Perfil de Usuario

Opciones:

- Actualizar información.
- Cambiar contraseña.
- Consultar historial.

---

# Recuperación de Contraseña

### Pasos

1. Seleccionar "Olvidé mi contraseña".
2. Ingresar correo.
3. Seguir instrucciones enviadas.

---

# Cierre de Sesión

Para finalizar:

1. Seleccionar perfil.
2. Presionar cerrar sesión.

---

# Recomendaciones

- No compartir credenciales.
- Cerrar sesión al finalizar.
- Reportar comportamientos inusuales.
