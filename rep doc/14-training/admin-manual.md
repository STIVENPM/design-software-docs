# Administrator Manual

## Objetivo

Describir las actividades administrativas necesarias para gestionar el Sistema de Gestión de Horarios SENA.

---

# Perfil Administrador

El administrador posee acceso a funcionalidades avanzadas de configuración y gestión.

---

# Funciones Principales

## Gestión de Usuarios

Permite:

- Crear usuarios.
- Modificar usuarios.
- Desactivar usuarios.
- Consultar usuarios.

---

# Gestión de Roles

Permite:

- Crear roles.
- Modificar roles.
- Asignar permisos.

---

# Gestión de Permisos

Permite controlar:

- Acceso a módulos.
- Acceso a funcionalidades.
- Restricciones de seguridad.

---

# Gestión de Parámetros

Permite administrar:

- Configuraciones generales.
- Catálogos.
- Estados.

---

# Gestión de Auditoría

Permite consultar:

- Inicios de sesión.
- Modificaciones.
- Operaciones críticas.

---

# Gestión de Horarios

Permite:

- Supervisar programación.
- Validar conflictos.
- Realizar seguimiento.

---

# Monitoreo del Sistema

Consultar:

- Estado de servicios.
- Errores.
- Actividad reciente.

---

# Buenas Prácticas

- Revisar auditorías periódicamente.
- Mantener usuarios actualizados.
- Aplicar principio de mínimo privilegio.
- Gestionar accesos oportunamente.
