# UML Exports

## Objetivo

Almacenar las versiones exportadas de los diagramas para consulta rápida.

---

# Formatos Permitidos

- PNG
- JPG
- SVG
- PDF

---

# Beneficios

- Fácil visualización.
- Compartición con stakeholders.
- Inclusión en informes.

---

# Recomendaciones

- Mantener misma versión que el archivo fuente.
- Actualizar exportación cuando cambie el diagrama.
- Evitar exportaciones obsoletas.

---
