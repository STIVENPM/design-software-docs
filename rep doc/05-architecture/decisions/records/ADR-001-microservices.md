# ADR-001

## Título

Uso de arquitectura basada en microservicios.

## Estado

Aceptado

## Contexto

El sistema debe permitir escalabilidad,
mantenibilidad y desacoplamiento.

## Decisión

Implementar arquitectura de microservicios.

## Consecuencias

### Positivas

- Escalabilidad.
- Independencia.
- Despliegue separado.

### Negativas

- Mayor complejidad.
- Más monitoreo.
