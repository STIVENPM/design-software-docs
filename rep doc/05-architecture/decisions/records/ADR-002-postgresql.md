# ADR-002

## Título

Uso de PostgreSQL como motor de base de datos.

## Estado

Aceptado

## Contexto

El sistema requiere:

- Integridad referencial.
- Transacciones.
- Escalabilidad.

## Decisión

Utilizar PostgreSQL.

## Consecuencias

### Positivas

- ACID.
- Open Source.
- Alto rendimiento.

### Negativas

- Curva de aprendizaje.
