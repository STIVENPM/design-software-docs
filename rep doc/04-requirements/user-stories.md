# User Stories

## Introducción

Las historias de usuario representan necesidades funcionales expresadas desde la perspectiva de los usuarios del sistema.

---

# HU-001 Registrar Usuario

Como administrador

Quiero registrar usuarios

Para controlar el acceso al sistema.

## Criterios de aceptación

* Documento único.
* Correo único.
* Rol obligatorio.

---

# HU-002 Gestionar Roles

Como administrador

Quiero administrar roles

Para controlar permisos.

## Criterios

* Crear rol.
* Editar rol.
* Consultar rol.
