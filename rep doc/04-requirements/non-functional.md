# Non Functional Requirements

## Introducción

Los requisitos no funcionales establecen las características de calidad que debe cumplir el sistema.

---

# RNF-001 Disponibilidad

El sistema deberá mantener una disponibilidad mínima del 99%.

---

# RNF-002 Rendimiento

El tiempo de respuesta promedio no deberá superar los 3 segundos.

---

# RNF-003 Escalabilidad

La arquitectura deberá permitir crecimiento horizontal mediante microservicios.

---

# RNF-004 Seguridad

El sistema deberá implementar:

* JWT.
* Control de acceso.
* Gestión de permisos.
* Auditoría.

---

# RNF-005 Usabilidad

La interfaz deberá ser:

* Intuitiva.
* Consistente.
* Accesible.

---

# RNF-006 Compatibilidad

El sistema deberá funcionar correctamente en:

* Google Chrome.


---

# RNF-007 Mantenibilidad

El código deberá seguir estándares definidos.

---

# RNF-008 Portabilidad

El sistema deberá desplegarse en diferentes entornos.

---

# RNF-009 Integridad

Toda la información deberá mantener integridad referencial.

---

# RNF-010 Confiabilidad

El sistema deberá recuperar operaciones fallidas sin pérdida de información.

---

# RNF-011 Auditoría

Toda operación crítica deberá quedar registrada.

---

# RNF-012 Respaldo

La base de datos deberá contar con mecanismos de respaldo.

---

# RNF-013 Accesibilidad

La interfaz deberá considerar principios básicos de accesibilidad digital.

---

# RNF-014 Observabilidad

El sistema deberá registrar:

* Logs.
* Métricas.
* Eventos.

---

# RNF-015 Calidad

Todo desarrollo deberá cumplir Definition of Done.
