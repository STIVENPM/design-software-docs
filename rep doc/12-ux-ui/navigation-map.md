# Navigation Map

## Objetivo

Describir la estructura de navegación del Sistema de Gestión de Horarios SENA.

Este documento permite visualizar cómo se conectan las diferentes funcionalidades de la aplicación.

---

# Flujo General

Login

↓

Dashboard

↓

Módulos del Sistema

---

# Pantalla de Inicio de Sesión

Funciones:

- Iniciar sesión
- Recuperar contraseña

Destino:

Dashboard

---

Punto central de navegación.

# Navegación Esperada

La navegación deberá:

- Ser intuitiva.
- Reducir clics innecesarios.
- Mantener consistencia visual.
- Permitir regresar fácilmente a pantallas anteriores.
