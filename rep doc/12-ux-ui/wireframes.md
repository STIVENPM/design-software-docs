# Wireframes

## Objetivo

Documentar los prototipos de baja fidelidad utilizados para definir la estructura visual del Sistema de Gestión de Horarios SENA.

Los wireframes permiten validar distribución de información y navegación antes de iniciar el desarrollo visual definitivo.

---

# Wireframe Login

## Componentes

- Logo SENA
- Campo correo
- Campo contraseña
- Botón iniciar sesión
- Recuperar contraseña

---

- Indicadores
