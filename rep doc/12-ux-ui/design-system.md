# Design System

## Objetivo

Definir los lineamientos visuales y de interacción que garanticen una experiencia consistente en todo el Sistema de Gestión de Horarios SENA.

El Design System servirá como referencia para diseñadores, desarrolladores frontend y stakeholders involucrados en el proyecto.

---

# Principios de Diseño

La interfaz deberá cumplir los siguientes principios:

## Simplicidad

La información deberá mostrarse de forma clara y comprensible.

## Consistencia

Los componentes visuales deberán mantener el mismo comportamiento en todas las pantallas.

## Accesibilidad

La aplicación deberá facilitar la navegación para todos los usuarios.

## Eficiencia

Las tareas frecuentes deberán completarse con la menor cantidad de pasos posible.
