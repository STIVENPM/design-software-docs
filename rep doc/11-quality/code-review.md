# Code Review

## Objetivo

Establecer las reglas para la revisión de código dentro del proyecto.

---

# Principios

Todo cambio deberá:

- Ser revisado.
- Ser aprobado.
- Ser documentado.

---

# Flujo

Desarrollador

↓

Commit

↓

Push

↓

Pull Request

↓

Code Review

↓

Merge

---

# Aspectos a Revisar

## Calidad

Validar:

- Legibilidad.
- Mantenibilidad.
- Modularidad.

---

## Arquitectura

Validar:

- Cumplimiento de arquitectura.
- Separación de responsabilidades.
- Buenas prácticas.

---

## Seguridad

Validar:

- Manejo de credenciales.
- Control de acceso.
- Validaciones.

---

## Rendimiento

Validar:

- Consultas eficientes.
- Uso adecuado de recursos.

---

# Checklist

## Frontend

- [ ] Componentes reutilizables
- [ ] Manejo de estados
- [ ] Navegación correcta
- [ ] Accesibilidad

---

## Backend

- [ ] Controladores limpios
- [ ] Servicios desacoplados
- [ ] Validaciones
- [ ] Manejo de excepciones

---

## Base de Datos

- [ ] Relaciones correctas
- [ ] Índices adecuados
- [ ] Integridad referencial

---

# Aprobación

Se recomienda:

- Mínimo un revisor.
- Aprobación antes del merge.
